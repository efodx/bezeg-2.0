# Keep count values visible

The Bernstein degree field contains its value, but its compact input has a larger minimum width than its wrapper. Its right-aligned digit extends under the following plus button.

Acceptance criteria:

- The editable field fits between the minus and plus buttons at 390px, 614px, and desktop widths, including enlarged text.
- Bernstein's initial degree is visibly 1; buttons, direct entry, and keyboard stepping retain the existing 0–5 range and update the graph.
- Shared count controls retain their accessible labels and touch targets. No mathematical, route, or preset behavior changes.

Verify field/button bounds in a real browser, inspect the control visually, run existing numeric-control unit tests, typecheck, build, and perform focused browser smoke checks.
