# 03 Curate the complete still set

Source: [spec](../../specs/representative-demonstration-previews.md), per-demonstration scene targets and acceptance 1–8. Depends on: [02](02-deterministic-capture.md).

## Goal and scope

Implement the per-route poster recipes and regenerate every shipped demonstration's genuine 720×440 PNG. Own recipe content and reviewed poster output; coordinate shared script/mapping/manifest writes with task 04. Do not edit graph mathematics, route defaults, lessons, preset behavior or homepage artwork to improve thumbnails.

## Deliverables and acceptance

- Account for every refreshed scene target with a recipe, outcome evidence and own-route capture. Replace every shipped placeholder. Unmet targets receive an explicit disposition rather than a completion claim.
- Preserve original control points, weights and functions. Bernstein has four cubic basis functions, repeated subdivision has four covering pieces, Farin points are visible, and iterative/reveal previews show the intended state.
- Use focused coordinate windows for analysis and equal unit scales for geometry. Preserve discontinuities, distinguish approximation from exact curves, and make supporting polygons and necessary labels readable at 360×220.
- Implement affine comparison using two genuine captures if practical, following the source spec; record any unresolved composition limitation. Motion delivery alone does not silently waive the static comparison requirement.
- Review a complete contact sheet and every poster at actual card size. Record per-target exceptions and the exact stable capture checkpoint. Generated files, map and manifest must agree.

## Checks and evidence

Run focused recipe/manifest validation, catalog unit tests, TypeScript and production build. Verify affected subdivision/elevation invariance using existing relevant mathematical checks and inspect rational/PH/continuity images for fidelity. Record all-image visual coverage and remaining issues. Final independent reviews and integrated catalog/picker browser acceptance belong to task 06.
