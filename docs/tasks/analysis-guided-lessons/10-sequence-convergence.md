**Source spec:** [Analysis guided lessons](../../specs/analysis-guided-lessons.md), C1

**Dependencies:** Batch B released ([09](09-batch-b-release.md)); iterative playback ([00](00-family-and-playback.md), ADR 0012, ADR 0013)

**Status:** released 2026-10-16 ([14](14-batch-c-release.md))

## Part A: mathematics (`src/analysis/sequence.ts`, `sequenceModel.ts`)

- Named examples for integer `n >= 1`: `reciprocal` `1/n` (default, limit `0`), `alternating-reciprocal` `(-1)^n/n` (limit `0`), `alternating-sign` `(-1)^n` (no limit), `natural` `n` (diverges to infinity).
- The term `a_n` and the distance `|a_n - L|` to a candidate limit `L`.
- Certificate for a chosen `epsilon > 0`, candidate `L` and threshold `N`. It is formula-backed and never derived from a finite window of terms:
  - For a convergent example with `L` equal to its limit: `|a_n - 0| = 1/n <= 1/N` for every `n >= N`, so `N` works exactly when `N epsilon > 1`. The least working threshold is `N_min = floor(1/epsilon) + 1`. Compare without the rounding of `1/epsilon` (for example, check `N_min * epsilon > 1 >= (N_min - 1) * epsilon` in a test across the epsilon grid).
  - If `N` does not work, report the first failing index `n = N` (`|a_N - L| >= epsilon`).
  - For `L` different from the limit of a convergent example, give no certificate and say `L` is not the limit.
  - For `alternating-sign`, give no certificate. The farther of the values `1` and `-1` is at distance `1 + |L|` from `L`, and it recurs beyond every `N`, so the band fails whenever `epsilon <= 1 + |L|` (in particular for every `epsilon <= 1`). Only when `1 + |L| < epsilon` does the band contain every term; say that this single epsilon is satisfied but convergence requires every `epsilon > 0`. (Corrected during Part A: the first draft claimed this for every `epsilon > 1`, which fails for example at `L = 1`, `epsilon = 1.5`.)
  - For `natural`, give no certificate. `a_n > L + epsilon` for every `n > L + epsilon`, so the terms leave every band for good.
- Bounded domains (document the constants): `epsilon` in `[0.01, 2]` on a `0.01` grid, `L` in `[-2, 2]` on the same `0.01` grid, `N` an integer `1..1000`, and revealed terms `terms` an integer `1..SEQUENCE_MAX_TERMS` (for example, `40`).
- A threshold beyond the revealed or visible index range is reported as such ("N = 101 is beyond the shown terms n <= 40; the bound holds for all n >= N by the formula"). It is never truncated to the window.
- Model: `{example, epsilon, limit, threshold, terms, certificateVisible}`, validated by the parser. Reject invalid values; never clamp them.

## Part B: graph (`src/graphs/functions/SequenceGraph.tsx`)

- Points `(n, a_n)` for `n = 1..terms`, the band `L +- epsilon` as a shaded strip with dashed edges, the line `y = L`, and a vertical marker at `n = N`. Terms inside and outside the band differ by shape, not by colour alone.
- Controls: example select; native number fields for `epsilon`, `L`, `N`; Next step (reveal one more term), Play/Pause and Reset (back to one term) through `IterationController`; a Show certificate button.
- Edits to the example, `epsilon`, `L` or `N` pause playback. Changing the example loads its default model with `terms = 1` and the certificate hidden.
- Playback stops at `SEQUENCE_MAX_TERMS`.

## Part C: lesson

5–7 steps:
1. Prerequisites and the definition with its quantifiers, using `1/n` with the band.
2. Learner picks `N` for `epsilon = 0.1`, then the certificate reveal (`N_min = 11`).
3. A smaller `epsilon` whose `N_min` lies beyond the shown terms.
4. `(-1)^n/n`.
5. `(-1)^n`: a band that contains a finite window of terms is no certificate.
6. `n`.
7. Handoff.

Add `sl`/`en` content, tests and a smoke row.

## Implementation notes

- **Part A.** `src/analysis/sequence.ts` and `sequenceModel.ts`: epsilon is handled as integer hundredths, so `N_min = floor(100/k) + 1` and "N works" (`N k > 100`) are exact; off-grid values are rejected, not rounded. The certificate is a discriminated result (`certified`, `threshold-fails`, `not-the-limit`, `oscillating`, `epsilon-satisfied`, `divergent`), each with `thresholdBeyondTerms`. `SEQUENCE_MAX_TERMS = 40`; the iteration controller uses `SEQUENCE_MAX_STEPS = 39` and `nextSequenceStep`. Defaults: `terms = 1`, threshold `5`, epsilon `0.1` (convergent) or `0.5` (others).

## Acceptance criteria

- For `1/n` and `(-1)^n/n` and every `epsilon` on the grid, `N = floor(1/epsilon) + 1` satisfies `|a_n - 0| < epsilon` for every `n >= N` (proved by the `1/N` bound and checked at `n = N` and beyond), and `N - 1` fails at `n = N - 1` when `N > 1`.
- `alternating-sign` and `natural` never receive a certificate, whatever the window, `epsilon` or `L`.
- A threshold beyond the visible range is reported honestly. `epsilon <= 0` is rejected.
- Next step applied k times and k played steps give the same model. Playback stops at the limit, pauses on edits, scene changes and capture, and never starts on preset load.
- Controls and lesson actions give equivalent configurations. Presets round-trip, and invalid data gets an actionable error.
- **Model and vocabulary.** The model is `{example, epsilon, limit, threshold, terms, certificateVisible}` (Part A). Closed vocabulary: parameters `sequence-epsilon`, `sequence-limit`, `sequence-threshold`; visibility target `sequence-certificate`; choice `sequence-example` (`reciprocal`, `alternating-reciprocal`, `alternating-sign`, `natural`); animation id `sequence` (commands `play`, `pause`, `replay`, `next-step`, `reset`; `stop` is rejected) and scene action `run-sequence-command` (`next-step` | `reset`; play and pause are not scene actions). `src/graphs/base/presets/PresetImport.ts` registers collection `sequence` with its own diagnosis: the example list, the epsilon grid and range ("multiple of 0.01 between 0.01 and 2"), the candidate limit range, the integer threshold `1..1000`, the integer term count `1..40` and the `certificateVisible` flag each get a specific actionable message; wrong types and missing fields keep the generic function-data message. Route `/analysis/sequence`, Analysis family entry (8 entries, 42 routes), lesson availability and a placeholder preview (`catalog/sequence.png`, a copy of the Taylor placeholder; the Batch C release task regenerates previews).
- **Reject, never clamp.** `setEpsilon`, `setLimit`, `setThreshold` (so also number fields and lesson actions) throw `DomainError` and leave the model unchanged for an off-grid, zero, negative or out-of-range epsilon, an `L` outside `[-2, 2]` or off the `0.01` grid (arithmetic noise such as `0.1 + 0.2` is snapped, a real off-grid value such as `0.001` or `1e-10` is rejected, never rounded), or a non-integer or out-of-range `N`; floating-point noise is cleaned only where it is noise (epsilon snaps through its hundredths, `L` through `cleanNumber`). `setExample` loads the example's default model (`SEQUENCE_EXAMPLE_MODELS`: one term, certificate hidden) and its own board view. Editing epsilon, `L` or `N` stops playback but keeps the revealed terms and the reveal; a repeated value is not an edit; Show certificate does not stop playback. `terms` is the iteration index and is saved with the preset (running state is not): the controller is reset to `terms - 1` after every edit, import and restore, so k Next steps and k played steps give the same model, and a preset with all 40 terms reopens as a finished iteration. Playback interval 500 ms (`SEQUENCE_STEP_INTERVAL_MS`).
- **Board.** Fixed pool of 87 objects whatever the example, term count or reveal: the band as one closed filled curve, its two dashed edges, the solid line `y = L`, the dotted vertical marker at `n = N` (hidden when `N` lies outside the view), a pool of 40 cross-shaped points (terms outside the band) and 40 filled circles (terms inside), the marker label and one caption. A term is a filled circle inside the open band and a cross outside it, so inside and outside differ by shape and not only by colour; the boundary case `|a_n - L| = epsilon` (for example `a_10 = 0.1` at epsilon `0.1`) is a cross, decided in integers by `isTermInBand`. The caption (bottom-right) has the formula, `epsilon, L, N`, the shown and in-band counts, one verdict line (neutral colour while hidden, green when `N` works, brown for every refusal), a line "N is beyond the shown terms" and a key line; the last two disappear below 520 px, and the marker label is `N` alone there (full `N = 5` on wider boards). Each example has its own view (`[-3, 1.5, 43, -1.5]` for the two convergent examples, a taller bottom for `(-1)^n` and `n` so that the caption clears the terms and the axis). Because the index and the value need different scales, `BaseGraph` gained `equalAxisUnits` (default `true`, so every other graph is unchanged); `SequenceGraph` returns `false`, and the places that applied a stored box with equal units (scene default view, example view of an imported preset, stored preset view, restored lesson scene, fit) now pass that flag.
- **Readout ids.** `terms`, `epsilon`, `limit`, `threshold`, `last-term`, `distance`, `in-band`, `in-band-count`, `certificate`, `n-min`, `bound`. `certificate`, `n-min` and `bound` read "skrito" / "hidden" until revealed; afterwards `certificate` is one of "N deluje", "N ne deluje", "L ni limita", "ni certifikata (nihanje)", "izpolnjen le ta ε", "ni certifikata (neomejeno)"; `n-min` and `bound` (`1/N = value`) are numbers for the two convergent verdicts and an em dash otherwise. Statuses (words, stable ids `data-sequence-status`): `hidden` or the verdict kind (`certified`, `threshold-fails`, `not-the-limit`, `oscillating`, `epsilon-satisfied`, `divergent`), then `beyond-terms` (the revealed certificate is about an `N` beyond the shown terms), `n-min-beyond-terms` (the least working `N` is beyond the shown terms, with a variant for beyond all 40) and `complete` (all 40 terms shown). The alternating-sign rule follows Part A: no certificate whenever `epsilon <= 1 + |L|`, and `epsilon-satisfied` only for `1 + |L| < epsilon`.
- **Controls.** Example select; native number fields for `epsilon` (step 0.01), `L` (step 0.1) and `N` (step 1) with range hints; a native group of Next step, Play/Pause (label swap, no `aria-pressed`) and Reset to one term (`data-action="next-step"`, `"play-pause"`, `"reset"`, `aria-disabled` rather than `disabled` so keyboard focus survives the last term or the start of playback); a native Show/Hide certificate button (`data-action="toggle-sequence-certificate"`, `data-revealed`). The shared legend gained two additive swatch kinds, `dot` and `cross`.
- **Lesson.** Seven steps (`sequence-guided`; frames 2 + 3 + 2 + 2 + 2 + 2 + 2 = 15): (1) the definition with its quantifiers for `1/n` at `epsilon = 0.1`, eight terms, none in the band, prediction for `N = 5`; (2) `N_min = 11`, `N = 10` fails on the band edge, with the worked example and the certificate shown (the one step whose scene reveals); (3) `epsilon = 0.01`, all 40 terms and none in the band, prediction of `N_min = 101` from the formula, beyond all shown terms; (4) `(-1)^n/n` at `epsilon = 0.1`: same distance, same `N_min`; (5) `(-1)^n` at `epsilon = 1.5`, where the band holds every shown term yet no certificate is possible, then `epsilon <= 1 + |L|`; (6) `n`, prediction including `L = 2` (leaves the band from `n = 3`); (7) a candidate `L` that is not the limit (`L = 0.5` for `1/n`) and the handoff. Prediction steps (1, 3-7) hide the certificate, ask the learner to predict and press the graph's own Show certificate, and carry no calculation frame; results are in `expectedObservations` and recapped in the next step.
