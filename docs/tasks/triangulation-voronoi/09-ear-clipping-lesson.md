## Decisions (handler 16, 2026-11-01)

- **Overlays.** `reflex`, `triangulation`, `colouring` and `guards` join `POINT_SET_OVERLAY_NAMES` (`src/compgeo/pointSetModel.ts`). Only `EarClippingGraph` owns them; the other point-set graphs keep rejecting them through their own overlay lists.
- **Trace step action.** The triangulation, colouring and guard overlays draw only at `done`, and the comb's trace has many events, so a lesson must reach a step without a long run of `next-step` actions. A new operation `{kind: 'point-set', operation: 'set-trace-step', step: number | 'end'}` pauses playback and sets the step (a number is clamped like a stored Preset step; `'end'` is the last step). `EarClippingGraph` handles it; the base class rejects it with `UnsupportedLessonActionError`, so other graphs reject it until they adopt it (the sweep lessons may). Alternative: a shared `finish` animation command. Rejected because `LESSON_ANIMATION_COMMANDS` is shared with other families' playbacks.
- **Animation.** `EarClippingGraph` registers `algorithm-trace` (`next-step`, `reset`, `play`, `pause`, `replay`) through the same transitions as its buttons, as `HullTraceGraph` does.
- **Chapter owner.** Until the triangulation chapter (F4) exists, the lesson uses the same interim chapter owner as the convexity lessons A1, A2 and A4.

## Acceptance

1. **Actions** as decided above. `lessonCatalog.ts` `sceneActions()` validates the new operation's shape and finiteness only. Every edit action pauses and returns to step 0; `set-overlay` keeps the step.
2. **Lesson** B1 (`ear-clipping`) in `src/learning/content/compgeoGuidedLessons.ts`; remove `lesson: false` from `ear-clipping` in `src/demonstrations.ts` and its id from the list in `lessonCatalog.test.ts` (near line 186). The spec's seven steps: (1) notched pentagon with reflex vertex \((3,2)\) marked; (2) predict which vertex can be cut off (trace overlay hidden); (3) Next steps through the ear tests, first ear \(\triangle(6,0)(6,4)(3,2)\), with the rule "first ear by lowest vertex index, counter-clockwise" stated; (4) the finished triangulation: \(n-2=3\) triangles, \(n-3=2\) diagonals; (5) Fisk's 3-colouring, classes \(\{(6,0),(0,4)\}\), \(\{(0,0),(6,4)\}\), \(\{(3,2)\}\); (6) one guard at \((3,2)\), \(\lfloor5/3\rfloor=1\), and its view; (7) the comb (\(n=11\), \(9\) triangles, class sizes \(4,4,3\), three guards), then free exploration. Playback is stopped by default and never autoplays.
3. **Text:** one-shot, Slovenian and English, terms from the spec's table (*uho*, *rezanje ušes*, *Fiskovo 3-barvanje*, *stražar*, *izrek o galeriji*). Every quoted value equals the scene's readout.
4. **Tests:** frames run in one synchronous sequence (AGENTS.md); the readouts at the quoted steps (first ear, triangle and diagonal counts, colour class sizes, guard count) for both examples; `set-trace-step` clamps and `'end'` equals Next until done; `next-step` ×k equals Next ×k; the new overlays are rejected by `HullTraceGraph` and accepted by `EarClippingGraph`; Back and a scene change pause playback and leave no pending scheduler callback.
