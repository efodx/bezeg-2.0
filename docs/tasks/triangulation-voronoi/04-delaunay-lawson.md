1. `incrementalTriangulation(points)`: grid points (validated as the other kernels do), at most 40 (`RangeError` beyond, like the other kernels). Refuse with a typed reason fewer than three points, duplicate points and all points collinear (reuse 03's refusal kinds where they fit). Insert in lexicographic order of \((x,y)\). The leading points collinear with the first two form a chain; the first point off that line is joined to every chain segment. Each later point \(q\) is joined to every hull edge \((a,b)\), taken counter-clockwise, that it sees **strictly** (`orient(a, b, q) < 0`); a hull edge collinear with \(q\) is not joined, so no degenerate triangle arises and the old endpoint becomes a collinear hull point. (Each new point is the lexicographic maximum, so it is a vertex of the new hull and sees at least one edge strictly.) The result goes through `createTriangulation`; a refusal there is an internal error (throw), not a user refusal.
2. `lawsonTrace(tri)`: from any valid `Triangulation`. Repeat: scan the interior edges in lexicographic order of the sorted vertex-index pair, as `illegalEdges` orders them; each scanned edge emits `test` with the incircle sign of the opposite vertex (and the exact value from `incircleValue` for the readout). The first edge with sign \(> 0\) is flipped (`flip` event with the removed and the added edge; the fold applies 03's `flip`). Then the scan restarts from the first edge. A full scan without a positive sign emits `done`. This order is the one B3 example 2 states ("flipping the first illegal edge in lexicographic order"). Legal means `incircle <= 0`, so cocircular quadruples never flip. If `flip` refuses an illegal edge, throw an internal error: dBCKO's lemma says this cannot happen, and the tests rely on it. `predicateCount` counts `incircle` calls. An initial `phase` event carries the start triangulation, as in 06.
3. `foldLawson`, `lawsonStateAt`: the state is the current triangulation, the edge under test, the number of flips and `done`. `delaunayTriangulation(points)` = `incrementalTriangulation` then the final state of `lawsonTrace`. `angleVector(tri)`: all \(3T\) interior angles in degrees, sorted ascending, as doubles (display only; never used for a decision in the kernel).
4. Tests (`delaunay.test.ts`). Numbers rechecked by a handler script (`python -I`, 2026-10-31):
   - Example 1, quad \(a=(0,0),b=(4,0),c=(5,3),d=(0,2)\) with triangles \((a,b,c),(a,c,d)\): `incircleValue(a,b,c,d)` \(=64\) and the edge \(ac\) is illegal. One flip to \(bd\), then both tests give \(-64\) (\(\text{incircle}(b,c,d,a)\) and \(\text{incircle}(a,b,d,c)\)), and `done`. Angle vectors to two decimals: before \(19.65,30.96,40.60,59.04,101.31,108.43\), after \(26.57,37.87,60.26,63.43,81.87,90.00\).
   - Example 2, B2's \(p_0..p_6=(0,0),(8,0),(9,6),(4,8),(-1,5),(3,3),(6,3)\) from T0 \((1,2,6),(1,5,4),(1,6,5),(2,3,4),(4,0,1),(4,5,6),(6,2,4)\): exactly three `flip` events, removing \(p_1p_4\), \(p_2p_4\), \(p_4p_6\) in that order. Result as index sets: \(\{0,1,5\},\{0,4,5\},\{1,2,6\},\{1,5,6\},\{2,3,6\},\{3,4,5\},\{3,5,6\}\). Smallest angle \(25.35^\circ\), against \(1.91^\circ\) in T0.
   - `incrementalTriangulation` on the same seven points gives \(\{0,1,6\},\{0,4,5\},\{0,5,6\},\{1,2,3\},\{1,3,6\},\{3,4,5\},\{3,5,6\}\) with illegal edges \(p_0p_6, p_1p_3\); Lawson flips those two and reaches the same Delaunay set.
   - Unit square \((0,0),(0,1),(1,0),(1,1)\): incremental gives \(\{0,1,2\},\{1,2,3\}\); the only interior edge tests with value \(0\); no flip.
   - Collinear cases: points on one line refused; collinear prefix (for example \((0,0),(0,2),(0,4),(3,1)\)) and a point collinear with a hull edge (for example \((0,0),(0,1),(1,0),(2,0)\)) give valid triangulations with the \(2n-2-k\) count.
   - A brute-force oracle **in the test file only**: all counter-clockwise triples whose circumcircle has every other point strictly outside (`incircle < 0`). On random general-position grid sets (no three collinear, no four cocircular, checked exactly; \(n\le14\); bounded attempts, a few hundred sets) `delaunayTriangulation` equals the oracle as index sets.
   - Random sets **with** degeneracies (small coordinate range, collinear and cocircular points allowed): the final triangulation passes `createTriangulation`, `illegalEdges` is empty, and every triangle's circumcircle has no point strictly inside (`incircle > 0` never).
   - Random start: from `incrementalTriangulation`, apply random successful `flip`s (bounded), then `lawsonTrace` terminates with `done`. At every `flip` event the angle vector increases strictly in lexicographic order, and the result equals the oracle in general position.
   - Flip order: the oracle and example 2 cannot see it (a variant that continues the scan after the flipped edge gives the same three flips on example 2, handler script). So the test file states the rule independently, repeatedly flipping the first entry of `illegalEdges` until it is empty, and compares its sequence of flipped edges with the trace's `flip` events on the random-start runs.
   - Trace: `lawsonStateAt` at the last index equals the final triangulation; index 0 is the start; `clampTraceIndex` handles stale indices; `predicateCount` is non-decreasing; exactly one `done`.
   - Report the largest trace length seen in the random-start test (the restart scan can emit about \(3n\) tests per flip).
   - Observed failures under at least two deliberate mutations (for example flip on `incircle >= 0`, which loops or breaks the square case; continue the scan after the flipped edge instead of restarting, which the flip-order reference must catch; join edges with `orient <= 0`).
