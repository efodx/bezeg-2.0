# Keep Bezeg as a static client-only app

Confirmed by the owner on 2026-10-08: Bezeg remains deployable as static files on GitHub Pages, with no backend, user accounts, or server database. Browser-local presets and file import/export remain supported; this keeps hosting simple and lets students and educators use the app without account setup, while accepting that presets are not automatically synchronized between devices. Technology upgrades must fit this constraint.
