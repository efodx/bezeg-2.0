# Roll out guided lessons by reviewed cohorts

Bezeg will expand Guided lessons from the three-pilot draft in reviewed mathematical cohorts, using an explicit capability matrix and allowlist. A Demonstration receives a Learn entry only after its graph-owned typed actions, prepared scenes, localized content, mathematical checks, and classroom/device review pass; routes that do not have a coherent supported lesson remain lesson-free. This avoids autogenerated or visually uniform lessons that weaken the mathematics while preserving the existing graph experience.

## Considered options

### Generate a lesson for every route

Rejected because route controls do not share one semantic model, and generic content would invent actions or teach implementation details as mathematics.

### Build one universal capability API

Rejected because it would make unrelated graph families depend on a broad, weakly typed action vocabulary. Shared primitives may live in base classes, but demonstrations retain ownership of family-specific meaning.

### Expose the Learn entry before review

Rejected because incomplete translations, unsupported scenes, or unverified expected observations would become part of the student experience.

## Consequences

The rollout requires more planning and review before each cohort, and Learn will not appear uniformly across the catalog. In return, lesson availability is an intentional product signal, graph ownership remains explicit, and unsupported or no-fit demonstrations stay safe and useful.
