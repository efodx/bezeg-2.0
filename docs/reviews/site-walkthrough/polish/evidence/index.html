Shell and label polish: before and after

Package B of the 2026-11-14 site walkthrough. The live site in this preview carries every change below: Home, Demonstrations, a chapter, Interval Sweep, Blossoming. Items marked “Waiting for you” are not on the public site; they stay on a local branch until you approve or change them.

H05 Header mark beside the name Waiting for you

The mark was a fixed 34 px tile beside a 30 px wordmark (28 px beside 21 px on phones). It is now sized from the wordmark (0.94 of its font size) and centred on the capitals, with a proportional gap. The icon file, the header height and the one-row phone header are unchanged. Alternative I did not build: keep the old size and only fix the vertical alignment.

D02 Catalog: topic list, family line on cards, card actions Waiting for you

Topic names drop from body size to 14 px so the list reads as navigation. The family line on each card takes the small-caps style the homepage carousel already uses. Open / Guided example stay minimal ghost buttons, at 13 px (was 12) with the homepage arrow. Card titles are unchanged. These screenshots also contain D01 (rounded capture corners).

L02 L03 Chapter previous / next and “All learning content” Waiting for you

One arrow drawing now serves all three controls, sized from the text and centred on it. The “Previous chapter” / “Next chapter” line is a semibold label in the link colour. Position, card size and the chapter-title typography are unchanged. For the return control there are two treatments: A (in the live preview) removes the border and fill so it reads as a quiet link with a hover fill; B keeps the bordered button and only swaps the arrow.

M01 M02 Interval Sweep and blossoming: math labels and the drag cursor Done

Interval Sweep points (and the points of the other 21 point-set graphs) now show the same pointer cursor as Bézier control points, and their labels, segment names and interval letters are typeset like other graph labels.
