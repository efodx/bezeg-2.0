# Bézier activity figures

The six activity cards now use static PNGs captured from their exact authored query URLs. Their reader captions and image alternatives are provided in Slovenian and English, while graph labels in the images remain Slovenian because the graph does not yet localize them. The affine caption describes the opened cubic example for translation, scaling, rotation, or reflection; the image does not invent a translated comparison.

`src/images/learning/bezier/manifest.json` records each source URL and authored action summary, the checked scene points/curves/visibility, output dimensions and SHA-256, source revision, build stamp, and hashes of the served entry bundles. The generator verifies that the local build output matches its stamp and that every served Vite entry bundle has identical bytes before capturing. Each figure uses a fresh browser context and board-only framing through the existing capture presentation helper. It fails on missing geometry, browser exceptions, an unprepared activity context, unexpected live curve samples, changed geometry after presentation, and clipped board content.

The Bézier and affine curves are checked at parameters 0, 0.5, and 1 against their authored endpoints and midpoint. Both quartic activities also check all ten interpolation points for `t = 0.5`. The quadratic Bernstein capture checks each live basis function at 0, 0.5, and 1, and the geometric-bounds capture requires the visible polygon in addition to the cubic controls and control polygon.
