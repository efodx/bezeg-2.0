- **P2 — Comparison title and visual affordance overstate what is shared/shown.** The comparison title at `patchGuidedExamplesAdvanced.ts:120` says “Same boundaries”; the tensor conversion in `TriangularTensorComparison.ts:9-21` preserves only the two origin edges (`u=0` and `v=0`), and its third edge is generally different (the existing `TriangularTensorComparison.test.ts:92-94` checks that difference). It does not evaluate each piece at local `u=1`/`u=0` and compare those results, so the specific seam-coincidence observation at content line 49 is supported by underlying P5 math tests but not directly by this authored-scene test. Add the two local endpoint checks if this test is intended to validate that displayed claim.
