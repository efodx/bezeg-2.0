# JSXGraph compatibility follow-up

Observed on the pre-fix previews at ports 4396 (JSXGraph 1.14.1) and 4398 (1.9.2). Browser inventory scripts and complete JSON captures are in this directory.

The default Bézier batch scene had 52 registered objects before capture and 50 afterward on 1.14.1; the 1.9.2 baseline remained 50 before and after. The two missing 1.14.1 objects were `jxgBoard1G25` and `jxgBoard1G26`, JSXGraph's hidden pointer-sketch curves in `board.sketches[0..1]`; `board.sketch` aliases the first. Both were still referenced by those board fields after batch restoration, but no longer existed in `board.objects` or `board.objectsList`. The inventory found no axis-label objects missing. The closure now visits the actual `board.sketches` and `board.sketch` references, avoiding a type-based sweep that could retain future scene-owned curves.

With weights switched on for the four-point rational curve, the upgrade rendered four connected and visible objects with `elType: "smartlabel"`, class `smart-label-point2`, and plaintext `w_{0}=1.00` through `w_{3}=1.00`. The baseline rendered the same labels as `elType: "text"`. The old `boardStats` and `boardWeights` filters accepted only `text`, so they missed the upgrade's four rendered weight labels and their values. Both helpers now accept `text` and `smartlabel` while retaining the CSS-class, visibility, connection, and numeric assertions.

On the trigonometric lesson route, the upgrade rendered two visible curves with SVG path lengths about 1017.60 and 1224.98; the first curve had only two entries in `object.points`, while the second had 127. The baseline rendered the corresponding two curves with 1025 points apiece. The old `points.length > 2` rule therefore reported one drawn curve on the upgrade even though both paths had nonzero rendered length. `drawnCurves` now checks the connected visible path's measured SVG length, so straight two-point curves count and collapsed zero-length remainder curves stay excluded.

`GraphTransientState.test.tsx` now checks that the two board sketch references remain registered through figure-batch scene replacement and are removed when their board is unmounted. `boardSignature` now records `label` and `smartlabel` objects. The handler subsequently verified these changes with the full passing just check (192 files / 3,687 tests), a deliberate mutation of sketch preservation, and the full production smoke (243/243). See [final audit](jsxgraph-upgrade.md) for exact logs. The inventories above describe the pre-fix diagnosis.
