## Consumer inventory

- **Board creation/defaults:** `src/graphs/base/GraphSession.ts` passes through `JSXGraph.initBoard`; `src/graphs/base/BaseGraph.tsx` selects axes, fixed bounds, hidden navigation/fullscreen/screenshot/copyright. It does not set a renderer or quality option. `src/graphs/curves/ph/HodographInputBox.tsx` creates a second SVG-default board and calls both `resizeContainer()` and `setBoundingBox()`.
- **Custom curves:** `updateDataArray` occurs in `ComplexMultiplicationGraph`, `UniformConvergenceGraph`, `TrigonometricFunctionsGraph`, `DefiniteIntegralGraph`, `DarbouxGraph`, `AccumulationGraph`, `AreaBetweenCurvesGraph`, `ArcLengthGraph`, `BisectionGraph`, `ContinuityGraph`, `FixedPointGraph`, and `SequenceGraph`, plus tests. JSXGraph's changelog from 1.9.2 through 1.14.1 contains no entry changing the `updateDataArray` contract; the curve plotting/simplification changes above can still affect the result.
- **Pointer/keyboard:** Bezeg registers a capture-phase `pointerdown` listener to invalidate JSXGraph's cached container position in `GraphSession`; the session owns board event subscriptions. Custom graph code has direct board events, point dragging and curve hit tests. Relevant upstream entries are the 1.11 keyboard/moveTarget work and 1.13.0 moveTarget fix; no direct keyboard listener API change is called out in 1.10–1.14.
- **Text and export:** MathJax board labels are enabled in `AxisStyles`, `PointStyles`, Bézier/PH graph sources and `JXGRationalBezierCurve`. `src/graphs/base/export/FigureCapture.ts` provides PNG capture and `SvgMathLabels.ts` injects MathJax SVG into the cloned board SVG. Upstream SVG/MathJax entries above should be checked against these separate export paths.
- **Bounds and resize:** `setBoundingBox()` is used across graph families for initial/scene/preset/fit state, while `resizeContainer()` is owned by `GraphSession` and the PH child editor. The changes above include baseline fixes, 1.11 maxBoundingBox handling, and hidden-container plotting in 1.13.2.
- **TypeScript:** `src/types/jsxgraph-augment.d.ts` augments upstream declarations. Release notes only call out missing declarations for 3D in 1.13.3 and an unspecified missing entry in 1.14.1; typecheck will identify any changed 2D signatures.

## Scope notes

The releases add substantial 3D behavior, but this dependency-only slice must not introduce 3D surface code. The separately measured JSXGraph 1.9.2 performance and historical implementation claims remain evidence about that version; they should not be silently rewritten as 1.14.1 results. Current dependency references are updated in `docs/research/curve-renderer-options.md`, `docs/current-architecture.md`, and the surface research notes.

## Read-only preview validation

`scripts/demonstration-preview-capture-api.cjs` is a CommonJS consumer API, not a CLI and has no validation-mode argument. Its functions are consumed by `tests/smoke-catalog.cjs`; `validateGeneratedPreviews()` validates the currently published poster/motion manifests, asset checksums, dimensions, route coverage and motion evidence without capturing or writing files. The concrete read-only invocation is:

```sh
node -e "const result=require('./tests/smoke-catalog.cjs').validateGeneratedPreviews(); console.log(JSON.stringify({captures:result.manifest.captures.length,motions:result.manifest.motions.length},null,2))"
```

This validates existing output only; it does not exercise the upgraded renderer's new preview pixels. Running the capture generator would write staging/published assets and is outside this audit.
