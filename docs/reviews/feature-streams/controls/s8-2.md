# Controls step 8, slices 2 and 3: owned standalone scene slot, Blossom and NURBS migrated (PARTIAL handoff)

Status: implementation and tests written; final verification was still running when the budget signal arrived. No commits.

## Design
- `src/graphs/base/OwnedScene.ts` (new): `SceneDeclaration<Scene>` (`create(board)`, `sync(scene): boolean`, false = rebuild, idempotent `dispose`), `SceneSlot<Scene>` (one per GraphSession: `current`, `rebuild`, `reconcile`, `release`) and `constructOrSweep(board, construct)` (on a throw removes every board object created since it began, rethrows). The slot registers `release` as a session cleanup (runs before `freeBoard`); `release` clears before `dispose`; `rebuild` creates only while the session is alive and disposes (never publishes) a scene finished after the session ended.
- `BaseGraph.tsx`: third generic `Scene = unknown`; `sceneDeclaration()`, `ownedScene`, `rebuildOwnedScene()`; slot created per mount after `createMainView`. Hooks in the replacement host: `initialize` (then `slot.rebuild()`), `disposeScene` (then `slot.release()`), `syncReplacedScene` (then `slot.reconcile()`); `flushStateChanges` calls `slot.reconcile()` before `onStateChange` when state changed.
- Blossom/NURBS declare `sceneDeclaration()` (create wrapped in `constructOrSweep`; sync = `fits` ? `scene.sync()` : false; NURBS `fits` compares knots so a replacement with different knots rebuilds). Deleted from both: `scene` field, `ensureScene`, `removeScene`, `syncReplacedScene`, `syncScene` (NURBS), `disposeFigureScene`, `unmount`. Kept: empty `override initialize() {}` (abstract in BaseGraph; ~39 subclasses under `noImplicitOverride`) and a private `scene` getter over `ownedScene` (characterization tests read `graph.scene`). Blossom still calls `rebuildOwnedScene()` on import and reset.
- Defect fix: `BSplineBlossomScene.ts` and `BSplineNurbsScene.ts` drag handlers return when `disposed`. The `test.fails` pin is a normal test.
- Behaviour change: Blossom replacement sync now rebuilds on a degree/count mismatch (before it only synced, rebuilt on commit).
- Tests: `src/graphs/base/OwnedScene.test.ts` (new, 10 tests), `standaloneSceneLifecycle.test.tsx` (pin flipped; new real-graph test "a construction failure releases what the half-built scene acquired and publishes no scene", both graphs).
