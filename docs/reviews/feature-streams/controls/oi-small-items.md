# Small open items (2026-11-11, third handler)

- **NumberInput integer hint.** An integer field's range refusal now reads "Vnesi celo število med {min} in {max}." / "Enter a whole number between {min} and {max}." (new key `number_integer_range_hint`; "celo število" follows the catalog's existing "cela števila" in `pointset_grid_step`). Non-integer fields keep `number_range_hint`. Tests: `NumberInput.test.tsx` (sl, en; failed before the change with the old text), `sharedControlBehaviour.tsx` gains `NumericSpec.integer`, and the integer-field expectations in `CountSetter.test.tsx` and `DarbouxGraph.host.test.tsx` were updated.
- **UnavailableButton `title` plus hidden description: closed by decision, no change.** Under HTML-AAM accessible description computation, `title` becomes the description only when `aria-describedby` (and `aria-description`) give none. The button always sets both together, so assistive technology gets the reason once, from `aria-describedby`. The `title` stays for pointer users. No screen-reader run (the carried gap).
- **`.inspector-playback button:disabled` (C6): rule removed.** `PlaybackButtons.tsx` is the only renderer of `.inspector-playback` and uses `aria-disabled`. Voronoi/Delaunay controls use `aria-disabled`, with no native `disabled`. The `[aria-disabled="true"]` rule stays, so there is no visual change.
