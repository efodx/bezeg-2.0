## Settled decisions (implement, do not reopen)

- **D-a Unavailable model.** One shared `UnavailableButton` (or similarly named, in `src/inputs/`) generalizing `PlaybackButtons`' model: when given a reason string it is `aria-disabled="true"` and stays focusable, carries the reason in `title` and a hidden description linked by `aria-describedby`, does not run its action on click/Enter/Space, and on press shows the reason in the notice region. Without a reason it is an ordinary button. `PlaybackButtons` is rebuilt on it with unchanged DOM contract (`data-action`, `data-playback-reason`, `inspector-playback`) so its tests and smoke pass unchanged.
- **D-b Notice channel.** One shared channel (a small class or hook in `src/inputs/` or `src/graphs/base/controls/`) holding at most one `Message` (`src/localization` `Message` type, rendered lazily so a language switch re-renders it), with `refuse(message)`, `clear()`, and a change callback the owner wires to its re-render. One `RefusalNotice` component renders it **alone** in its own `role="status" aria-live="polite"` region (not mixed with other status lines; C22). It carries a stable hook `data-refusal-notice`.
- **D-c Guard.** One function `guard(channel, action): boolean`: runs `action`; on success clears the channel and returns true; on `DomainError` sets the channel to `error.reason` (or a generic localized refusal when the error has only a string message — use the message text) and returns false; rethrows anything else. A refusal followed by an accepted edit clears the notice, including an accepted no-op (the Epicycle stale-refusal bug class).
- **D-d Field notices stay on the field.** Typed-field validation (unparseable, out of range, off-grid snap) speaks in the field's own hint, as 1a decided; the graph's channel carries model refusals. A model refusal surfaced through `onChange` returning false keeps using `rejectedHint`.
- **D-e Off-grid snap (decision 8, entry 3).** `NumberInput` gains an optional `grid` prop. On commit (Enter/blur) a value outside `[min, max]` is refused with the range hint (never clamped); a value inside but off the grid (beyond arithmetic noise — reuse `gridValue`/`gridUnits` semantics from `BaseFunctionGraph.tsx`; move the helpers to a neutral module if importing would create a cycle) is rounded to the nearest grid value, which is then checked against the range, passed to `onChange`, and the field shows a short hint naming the value it used, e.g. sl "Zaokroženo na {value0}." / en "Rounded to {value0}." (choose terms per the localization guide). The hint clears on the next accepted commit or edit. Models are not changed: they still refuse off-grid values. `integer` stays as it is.
- **D-f Unavailable fields and the lost draft.** `NumberInput` gains `unavailableReason?: string`. With a reason the input is `readOnly` and `aria-disabled="true"` (not `disabled`, so it keeps focus), the reason is linked by `aria-describedby`, arrow keys and commits do nothing. If it becomes unavailable while a draft is open, the draft is dropped and the reason is shown in the field hint (a commit would be refused anyway). Unmount while focused drops the draft silently — record this in your report as the known limit. Keep the existing `disabled` prop working for current callers.
- **D-g `CountSetter` at a bound.** The minus/plus buttons use the unavailable model instead of native `disabled`, with reasons "at least {value0}" / "at most {value0}" style text from the min and max (or caller-supplied reason props when given). Its reason shows in the setter's own status region on press. `tests/count-setter.smoke.spec.cjs:43` (`toBeDisabled`) must be updated to the new contract (aria-disabled plus the reason after press); that is a confirmed behavior change, not a regression.
- **D-h Correlation pilot.** Replace `CorrelationGraph`'s private `notice`/`setNotice`/`guarded` with the shared channel, guard and `RefusalNotice`. The refusal leaves the status group and renders alone; keep the `data-prob-correlation-status` lines for the other statuses. Keep its drag-refusal behavior as it is for now (decision 7's drag-limit silence is a later sweep).
