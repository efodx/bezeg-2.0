## After the change

P1 is a titled wrapper around `BezierCurveControls` (Edit tab); the graphs mount `CurveOperation` (`BezierCurveControls.tsx`): Slider, pressed Preview (omitted where the graph keeps the point on the board permanently), Apply as `UnavailableButton`. Rational Reset weight is an `UnavailableButton` (reason `weight_already_one`); `rational-weight-*` classes removed. Eslint suppression for `CurveWorkspaceControls.tsx` pruned.

## Visible changes (User impact)
- Edit tab: Preview/Apply now the shared pressed-preview buttons; Elevate gains a Preview; De Casteljau is a pressed button, not a switch; operations are `InspectorDisclosure`s. Shorten keeps its own end parameter (preserved, test kept).
- Repeated Subdivision graph: Apply is aria-disabled with the reason `subdivision_steps_limit` at the limit (before: silent no-op).
- Reset weight at weight 1 is unavailable with a reason.
- Slider/preview changes in the Edit tab no longer rebuild the workspace (`onApplied` only on Apply).
