# Wave 3 smoke E brief (O1 operation panel, R1f compgeo readouts)

Same frame as `w2-pa-smoke-brief.md` (role, setup reading, evidence and return rules); read it for those. Differences:

**Preview:** production build of commit `fc9680af` (includes `a3a713d7`, `6e27a812`, `7e925b59`), served by the handler from the clean worktree with `just preview 4327` at `http://localhost:4327/bezeg-2.0/`. Do not start or stop it. Route paths are in `src/demonstrations.ts` (compgeo routes are under `/compgeo/…`; Simson, Inversion and Inscribed angle are top-level, e.g. `/simson-line`).

**Group O, curve operation panel (decision 64; evidence `w3-o1.md`, `w3-o1r.md`).** Routes `/bezier/extrapolation`, `/bezier/elevation`, `/bezier/subdivision`, `/bezier/subdivision-2`, their rational versions (find them in `src/demonstrations.ts`), and the curve workspace (`/` or the workspace route) Edit tab with a selected curve. Each operation is one `CurveOperation` panel (`BezierCurveControls.tsx`): a parameter `Slider`, a Preview button with `aria-pressed` (only one preview at a time; omitted where the graph keeps the point on the board permanently), and Apply as an `UnavailableButton` (`aria-disabled`, focusable, its reason shown on press). Check: pressing Preview sets `aria-pressed="true"` and shows the preview on the board, pressing another Preview clears the first; Apply changes the curve and clears the preview; one Apply reason shown when unavailable; the Shorten operation's parameter slider changes the preview; in the workspace, closing an operation's disclosure clears its preview (board preview gone, `aria-pressed` false on reopen). Rational: Reset weight is an `UnavailableButton` with reason when the weight is already 1.

**Group G, compgeo readouts (decisions 63, 65; evidence `w3-r1f.md`).** Routes: Delaunay, Triangulation, Voronoi, Monotone partition, Euler line, Notable points, Simson line, Inversion, Inscribed angle. Check: step counters read 1-based "Korak k od N" / "Step k of N" (first step shows 1, never 0; `[data-delaunay="step"]` on Delaunay); readout chips are visible; each graph has one `LiveReadout` (`[data-readout-live]`) whose text changes once per settled change (after a drag ends, not during it) and visible readout blocks carry no `role="status"`/`aria-live`. Triangulation live text is in `[data-triangulation-live]`.

**Per route, five checks:** (1) loads, board and inspector, no console errors; (2) each changed control or readout behaves as named above; (3) one unavailable reason (Group O: Apply or Reset weight; Group G: n/a unless a step button is at an end); (4) keyboard: Tab to the control, operate with Space/Enter or arrows, visible focus; (5) language switch SL→EN→SL keeps the scene and relabels. On two routes per group also 390×844 with touch emulation: controls reachable, buttons at least 44 CSS px high.

Evidence: `docs/reviews/feature-streams/controls/w3-smoke-e.md`; screenshots under `.command-logs/w3-smoke-e/`. Return ≤300 words: route × check table, failures first with repro (selector, action, expected, observed), coverage gaps.
