# Shared graph controls, task 1 slice 3: worker evidence

## Changes
- `LiveReadout` moved to `src/graphs/base/controls/` (with test); six curve graphs and `CurvatureBezierCurveGraph.test.ts` import it from there. New: `muted` prop, `dataAttribute` prop, `SettledReadout.flush()` (publishes a pending change; `LiveReadout` calls it in a layout effect when `muted` turns false, so a status reported during Play appears at once on Pause rather than 500 ms later).
- De Boor, Sequence: visible status lost `role`/`aria-live`; `LiveReadout muted={playing}` with an owned `SettledReadout` (`report` in render, `cancel` on unmount). HullTraceControls: hidden paragraph replaced by `LiveReadout muted={playing} dataAttribute="hull-trace-live"`; its readout is fed with `replace` (discrete steps published at once, as before).
- `NumberInput`: always-mounted role-less `div.number-input-hint-region[aria-live=polite]` around the hint `<p id>` (no `role`). `CountSetter` unchanged (its `data-count-status` notice region keeps `role="status"`, empty until a refusal).
- `controlsSignature`: `aria-disabled` input -> `:disabled`; `button[aria-disabled="true"]` -> `button:<text>[:<pressed>]:unavailable`; doc comment names the mute rule.
- Tests: LiveReadout (mute rule, flush, settle, data attribute), De Boor and Sequence mute tests, `controlsSignature.test.tsx` (new), NumberInput wrapper test, hint queries by class in NumberInput/CountSetter/Slider tests (the other 9 files already used text or `.number-input-hint`).
