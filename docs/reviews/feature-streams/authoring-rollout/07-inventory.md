## Contract recap (the slot)

- `SceneDeclaration<Scene>` = `create(board)` (may throw, must self-clean), `sync(scene): boolean` (false = rebuild), `dispose(scene)` (idempotent): `base/OwnedScene.ts:9-25`. `constructOrSweep` removes board objects created during a failed construction: `OwnedScene.ts:34-48`.
- `SceneSlot`: `rebuild` (release, then create, dispose if the session ended meanwhile), `reconcile` (sync, else rebuild), `release` (clear then dispose): `OwnedScene.ts:54-93`. Registered as session cleanup at construction (`OwnedScene.ts:58`).
- Host wiring in `base/BaseGraph.tsx`: class generic `BaseGraph<S, D, Scene = unknown>` (`:102`); `sceneDeclaration()` hook (`:142`), `ownedScene` getter (`:147`), `rebuildOwnedScene()` (`:152`); slot built in `mount` after `createMainView` (`:877-878`); `reconcile()` runs on every committed state change before `onStateChange` (`:242`); replacement host: `disposeScene` = `disposeFigureScene()` then `slot.release()` (`:643-646`), `initialize` = `initialize()` then `slot.rebuild()` (`:654-657`), `syncReplacedScene` = hook then `slot.reconcile()` (`:658-661`); session dispose releases the slot and drops it (`:970-972`).
- Migrated references: `curves/bspline/BSplineBlossomGraph.tsx:49,121-151` and `BSplineNurbsGraph.tsx:66,138-167`. Pattern: third generic arg, empty `initialize()` (`Blossom:121`, `Nurbs:138`), `sceneDeclaration()` with `create` wrapped in `constructOrSweep`, `sync` returning `scene.fits(...)`-based boolean then `scene.sync()`, `dispose`, plus `private get scene()` as a test seam over `ownedScene` (`Blossom:149`, `Nurbs:165`). No `ensureScene`, `removeScene`, `syncReplacedScene`, `disposeFigureScene` or `unmount` overrides remain. Their scene drag handlers carry a `disposed` guard (`BSplineNurbsScene.ts:74-78`).

Registration: all 11 are in `graphFactories.ts` (`:81-84,96,106-113,157-171,214-217`), so each is in `allGraphFactories` and therefore in the teardown sweep (see Tests).
