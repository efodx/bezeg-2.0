## Review notes (2026-11-11)

A Haiku UI and accessibility review read the 3a, 3c and residual pairs and their measurements after the fact; the handler checked each of its findings against the images and the CSS.

1. **3a.** Switch boundary 3 → 4.11 : 1, checkbox 20 × 20. The review reported the slider track and thumb edge at 2.05 : 1 and rejected the slider. This was a measurement artefact: the capture script reads the range input's own computed border, not the `::-webkit-slider-runnable-track` and `::-webkit-slider-thumb` pseudo-elements, which `src/inputs/Slider.css:11-14` draw with the border token `#767f6c` (4.11 : 1 on the light surface). The thumb fill is the selected surface. The 7.45 : 1 Presentation figure comes from the same artefact. Accepted.
2. **3c.** Function-button boundary failures (1.48 and 2.47 : 1) are gone, and Presentation text failures fell from 8 to 0 (`cv-3c/sum-after.txt`). The review reported the Presentation header "Učenje" and "Demonstracije" buttons as cream on cream. `after-fine-pres-bezier_affine.png` shows them transparent on navy with cream ink, as fixed in 3b. The "inspector-tabs text 1.64 : 1" figure is the audit script's tab artefact: the tabs read cream on navy and navy on cream in the same image. Accepted.
3. **Residuals.** B-spline extraction buttons measure 38 px desktop, 44 px mobile, boundary 4.11 : 1 (5.55 : 1 in Presentation) and text 12.53 : 1, from `cv-resid-after/data/*/bspline__extraction.json`. The buttons sit below the screenshot crop, so this check is numeric only. "Dvigni stopnjo" in Presentation now uses the selected pair, cream with navy ink (`cv-close` vs `cv-resid-after` `presentation/bezier__elevation__edit.png`), as the spec decision chose. It reads as strongly as a primary action, which is the selected pair's look everywhere in Presentation. Accepted.
