- **Role:** implementation (media capture), edit permission in the stream-geometry worktree. Do not commit, push or delegate.
- **Goal:** every id in `POSTER_PENDING` (`src/demonstrationPosterPending.ts`, currently 24 ids from all streams) gets its catalog poster and clip, and the list becomes empty. Acceptance:
  1. `node scripts/capture-demonstration-previews.cjs` run as a **selective recapture** (`PREVIEW_RECAPTURE_IDS=<the pending ids, comma-separated>`) against a production preview on port 4313 (`PREVIEW_BASE_URL=http://127.0.0.1:4313/bezeg-2.0`). Existing posters stay byte-identical; only the new ids' assets, `src/demonstrationPreviewAssets.ts` and `scripts/demonstration-previews/manifest.json` change. Read `docs/commands.md` lines 30–40 for the recapture flags. Use `PREVIEW_RECAPTURE_PRESERVE_SOURCE_PROVENANCE=1` only if the script refuses because the source revision differs (expected: these ids have no retained media, but retained ones do). Use `PREVIEW_RECAPTURE_VERIFIED_PRESENTATION=1` only if the script refuses on a presentation-fingerprint change: first diff the capture tooling since the manifest's recorded revision (`git log <rev>..HEAD -- scripts/capture-demonstration-previews.cjs scripts/demonstration-preview-recipes.cjs scripts/surface-view-evidence.cjs`) and report what changed. If either flag would be needed for a reason you cannot explain, stop and report.
  2. `POSTER_PENDING` becomes `[]` (keep it an array literal: `tests/smoke-catalog.cjs` parses it). Remove any test exemption that existed only for pending posters (search `POSTER_PENDING` and "pending" in `src/DemonstrationsPage.test.tsx`, `src/learning/LearningPage.test.tsx` (the thumbnail count of `.learning-thumb img` and its comment), and tests under `tests/`); update counts to the new truth.
  3. Each new poster shows its Demonstration's graph, not a blank, error or loading frame. Open every new poster image with the Read tool and list one line per id: what is visible.
- **Scope:** generated media files, `src/demonstrationPreviewAssets.ts`, `scripts/demonstration-previews/manifest.json`, `src/demonstrationPosterPending.ts`, and the tests named above. Do not change recipes, graphs or the capture scripts; if a recipe fails, stop and report the id and error. Ignore untracked `docs/reviews/**` logs.
