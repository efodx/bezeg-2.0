## Settled decisions

- **One graph, two views.** `FourierCoefficientsGraph` serves F2 and F4 on one later route (Batch A precedent: one graph and one lesson for F1 + F3). Model `src/analysis/fourierCoefficientsModel.ts`: `view: 'projection' | 'decay'` plus the fields of both views, so stored Presets do not change when the decay view is drawn.
- **Projection fields.** `layout` from a closed list of fixed-breakpoint layouts (ADR 0034 §2): `abs` breakpoints \(\{-\pi,0,\pi\}\), no jumps, default values give \(|x|\) exactly (\(\pi,0,\pi\)); `jump` \(\{-\pi,1,\pi\}\) with a jump at \(1\) and at the seam, default \(\mathrm{sign}(x-1)\); `free` \(\{-\pi,-\pi/2,0,\pi/2,\pi\}\), no interior jumps, seam jump allowed, default \(0\) everywhere. A non-jump breakpoint has one value; a jump breakpoint has a left and a right value. The seam (\(\pm\pi\)) is one shared value unless the layout marks it as a jump, and the graph then shows the seam midpoint at \(\pm\pi\). Values: finite, in \([-4,4]\); drags snap to \(0{,}05\), keyboard steps \(0{,}05\) (Shift \(0{,}5\)); an import accepts any finite in-range value (so exact \(\pi\) survives). Out-of-range input is rejected with a visible reason, never clamped silently. Also `K` (integer \(1..32\), default \(16\)), `selected` = \(\{term: 'a' | 'b', k\}\) with \(0\le k\le K\) (\(b_0\) does not exist: reject), `overlay` (boolean, partial sum \(S_K\) on/off). Default model: projection view, `abs`, \(K=16\), selected \(a_1\) (the default \(|x|\) has \(b_k=0\)), overlay on.
- **Decay fields** (parsed and validated now, drawn later): `selections`, three distinct ids from the closed example list (default `square`, `abs`, `smooth`); `n` integer \(1..101\) (default \(11\)); `scale: 'linear' | 'log'` (default linear).
- **Projection drawing.** Board: \(f\) on \([-\pi,\pi]\) with vertical-only handles (two at a jump), the selected harmonic \(\cos kx\) or \(\sin kx\), the signed product \(f(x)\cdot\) harmonic shaded with distinct positive/negative fills plus a text legend, the overlay \(S_K\). Bar spectrum of \(a_k\) and \(b_k\) for \(k\le K\): find an existing secondary-chart pattern first (search the analysis/probability/numerical graphs for an SVG or auxiliary-board chart) and copy it; report which. Bars need an accessible text alternative (values in a table or list). Readouts with decimal commas: the selected coefficient, the mean square \(\tfrac1\pi\int_{-\pi}^{\pi}f^2\), the Parseval sum \(\tfrac{a_0^2}{2}+\sum_{k\le K}(a_k^2+b_k^2)\). Coefficients come from the kernel's closed-form piecewise integration (it splits at every breakpoint).
