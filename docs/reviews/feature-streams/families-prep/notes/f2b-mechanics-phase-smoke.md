## Smoke repairs (worker)

- Finding 1 cause (descent): the observer and `reframeToSize` existed, but "view unmoved" compared the box corner and the scale. A resize keeps the box centre and changes corners and scale (jsdom: units 49.99 to 66.09), so the check read the settled board as a moved view and never reframed. Fix: `viewOf()` in DescentGraph.tsx is the box centre; a pan or a zoom about a point moves it. Edge: a zoom exactly about the centre counts as unmoved.
- Logistic cause: no reframe at all; the opening window was computed for the transient height and `setBoundingBox(..., false)` keeps the box on resize. Fix: LogisticMapGraph.tsx `shownBox`, `reframeToSize`, debounced ResizeObserver (150 ms) with cleanup through `session.registerCleanup`; a box still equal to the drawn one is reframed. Phase had no defect.
