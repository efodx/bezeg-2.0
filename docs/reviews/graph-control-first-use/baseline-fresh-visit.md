# Baseline: ordinary fresh visit, all catalogue routes

Step 1 of the definition of done in [the task README](../../tasks/graph-control-first-use/README.md): what a fresh visitor must choose, what is visible on the board and what they must scroll to.

- **Date:** 2026-11-19.
- **Site:** https://efodx.github.io/bezeg-2.0/ (published master app). Entry asset `assets/index-4YFBiBaU.js`.
- **Viewports:** desktop 1440x900 (mouse); phone 390x844 (touch, isMobile, Pixel 7 user agent). Fresh browser context per route and view, clean storage, locale sl-SI (Slovenian default), Edit tab, nothing opened, 2 s settle after the board appeared.
- **Measured inspector width (desktop):** 310 px on all 138 routes (the `.workspace-inspector` element; grid column in `DemonstrationWorkspace.css`). On phone the inspector flows below the board at full width.
- **Raw data:** not kept. The capture is `node scripts/controls-sweep/fresh-visit.cjs all`. For each route and view, it records the controls with their name, role, page y, height and in-view flag, the board's y and the playback group's y, and one screenshot. Output goes to `.command-logs/fresh-visit/`. The first-task matching below was done by label, by hand.
- **Rows:** 138 (the 138 ids from `docs/tasks/graph-control-first-use/*.md`, each exactly once). All 276 loads succeeded; none failed.

## Reading the table

- y is the page y in px of the control's top edge. Desktop "in view" means fully inside the inspector's visible scroll region and the 900 px window. Phone "in view" means fully within the first 844 px of the page. Board drag rows count as in view when the whole board is within the first viewport; they do not test whether a draggable handle is identifiable.
- "N before" counts the distinct controls ahead of the matched control in Edit order (on phone the playback group sits directly under the board and comes first). Value fields and stepper buttons of the same control are not counted. "none before" means nothing else has to be passed.
- Matching is by label against the first task, chosen by judgement.
