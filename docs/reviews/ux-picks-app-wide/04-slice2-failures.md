# Task 04 slice 2: unit suites failing after the column removal

Run: `just unit src/graphs src/learning` (after the slice-2 changes and the test migrations): 286 of 768 files failed, 4234 of 14938 tests. The narrower `src/workspace src/graphs/base src/learning/runtime` run: 26 files, 1459 tests (GraphTransientState x4, graphTeardownContract, lessonRestoration x8 carry about 1400).

## Cause (sampled by message class, not checked file by file)

Almost all are one cause: tests mount a graph with `mountGraph` / `render(<GraphHost>)` and query a panel control synchronously. The Orodja card, and with it the graph's panels, now appears only after the async measure pass of `BoardCards`, so the controls are absent at the first query. Message classes: "Unable to find an accessible element" 349, "Unable to find a label" 177, `null.textContent` 55, `null.querySelectorAll` 38, "Unable to fire click, no DOM element" 36, "condition did not hold in time" 30. Not verified one by one: some may be the hidden-tab case (panels under `[hidden]` sections) or depend on the lesson column (slice 3).

Remedy candidates for the handler: (a) one harness-level wait (`mountGraph` async, or a helper in `realGraphTestHarness.tsx`); (b) render the Orodja body before the measure completes (design change); (c) migrate each suite.
