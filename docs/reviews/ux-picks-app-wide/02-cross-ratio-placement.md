# Cross-ratio (projective-cross-ratio): placement

No parameter is declared. The graph binds nothing in the parameter arbiter (task 01 left it out), so the three things the panel lets the learner change stay unbound and undeclared:

- **The seven handles (A-D on the first line, the centre O, M and N).** Their value would be an integer position, edited by a `PointListInput` row each; the learner changes them while watching the images, so they would be board controls, but there is no arbiter key to bind. They remain draggable on the board and in the present panel (declaration gap).
- **The example choice (default, harmonic, infinity, custom).** Four named options is a board choice by Taylor's rule, but it has no arbiter key either; not declared.
- **The selected handle.** It is transient selection state for keyboard stepping, not a parameter.

What is declared: the panel's sentences as notes (`original-ratio`, `image-ratio`, `limit`, `originals`, `images`, in the panel's order), its status sentence as the one status line (warning tone when the projection is undefined), and a seven-entry legend (lines p and p′, points A-D, centre O, points M and N, images, rays).
