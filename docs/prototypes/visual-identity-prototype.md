# Bezeg visual identity prototype

Throwaway UI prototype for the question: **Can Bezeg feel more distinctive by keeping the new palette and controls, while shifting from a notebook metaphor to a clean curve-laboratory interface?**

Open [`visual-identity-prototype.html`](visual-identity-prototype.html) directly in a browser. Use the fixed arrows or Left/Right keys to switch between:

- **A · Krivuljni laboratorij** — a flat warm canvas, family color markers, and a precise instrument panel.
- **B · Črnilo za projekcijo** — high-contrast presentation mode for classroom projection.
- **C · Kompaktni pogled** — graph-first narrow layout with a compact tool panel.

The curve, control points, parameter slider, construction toggle, topic markers, and editing modes are intentionally lightweight in-memory interactions. They are visual affordances, not production mathematics or persistence.

The current iteration deliberately removes paper, notebook, margin-note, and specimen language. It keeps the elderflower-adjacent colors, graph-first hierarchy, strong controls, and presentation contrast, but tests a more neutral mathematical-instrument identity.

This prototype does not change the React app, routes, renderer, preset format, or production styles. It is intended to answer which visual language is worth specifying before any bounded implementation work.
